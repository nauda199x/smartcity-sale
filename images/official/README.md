# Official-source media

This directory stores selected first-party project media used by Tìm Mua Smart City.

Current structure:

- `overview/` — project overview, park, landscape, and smart-ecosystem imagery.
- `gallery/` — general Smart City editorial imagery from the official gallery.
- `gateway-tower/` — exterior renderings, interior reference imagery, and unit layouts.
- `sapphire-parkville/` — ParkVille renderings, internal landscape, and unit layouts.

Filename convention: lowercase ASCII, hyphen-separated, subject first, for example `vinhomes-smart-city-central-park-kayak-01.webp`.

Every downloaded asset must retain source-page metadata in `data/official/asset-manifest.json` and receive meaningful `alt` text when published. Images are resized to the display need and converted to WebP rather than serving oversized originals. First-party provenance is not a copyright licence; any reuse permission or press-kit terms must be retained separately by the site owner.
