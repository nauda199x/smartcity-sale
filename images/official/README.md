# Official-source media

This directory stores selected first-party project media used by Tìm Mua Smart City.

Planned structure:

- `tong-quan/` — hero, aerial/project overview, location/masterplan.
- `tien-ich/` — Central Park, Sportia Park, Zen Garden, ecosystem amenities.
- `phan-khu/` — subdivision exteriors and internal amenities.
- `mat-bang/` — masterplans, tower typical floors and apartment layouts.
- `tai-lieu/` — thumbnails/previews for official brochures; source documents remain traceable to their official URL.

Filename convention: lowercase ASCII, hyphen-separated, subject first, for example `vinhomes-smart-city-central-park-kayak-01.webp`.

Every downloaded asset must retain source-page metadata in `data/official/` and receive meaningful `alt` text when published. Images should be resized to the display need and converted to WebP where practical rather than serving the original oversized file.
