# Marketplace Growth Phase 3

This phase turns the supply-side account work into repeat demand and crawlable inventory discovery.

- Members can save a filtered sale/rent search and see how many approved listings appeared since they last opened it.
- Saved searches are private per Supabase `auth.uid()` and are never exposed to anonymous visitors.
- Marketplace collection pages expose a Save search control without blocking anonymous browsing.
- SEO builds generate only inventory-backed phase/unit/tower landing pages, with minimum inventory thresholds to avoid empty or thin doorway pages.
- Generated landing pages join the normal sitemap scan and link back to the canonical sale/rent hubs and project information pages.
