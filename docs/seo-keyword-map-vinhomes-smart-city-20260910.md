# Vinhomes Smart City SEO keyword map — 2026-09-10

## Method

This map is based on live SERP review in September 2026, current competitor coverage, commercial intent, freshness sensitivity and the site's existing topical authority. It deliberately does **not** invent Google Keyword Planner volumes. Exact monthly volume requires first-party keyword-volume tooling; priority here is based on observable search-result competition, buyer/renter intent and whether timmuasmartcity.com has a credible page that can win the query without cannibalizing another URL.

Priority scale:
- **P0**: direct transaction / very close to transaction; build or strengthen now.
- **P1**: strong mid-funnel research that naturally feeds P0 pages.
- **P2**: useful informational traffic; build after P0/P1 coverage is strong.
- **Existing**: already has a suitable canonical target; improve that URL rather than make a duplicate article.
- **Dynamic**: let approved inventory generate the landing only when there is enough stock.
