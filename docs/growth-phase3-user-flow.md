# Saved-search user flow

1. Visitor opens Mua bán or Cho thuê and applies filters.
2. Visitor chooses **Lưu tìm kiếm**.
3. If already signed in, the normalized filter is saved immediately.
4. If signed out, the filter is kept locally and the visitor is sent to **Tin của tôi** to sign in/create an account.
5. After authentication, the pending filter is saved to the member account.
6. The dashboard shows the number of newly approved matching listings since the search was last opened.
7. Opening the search updates its last-seen timestamp; deleting removes only that private search and does not affect listings.
