## Editorial rule

- Every tower URL must show an actual floor-plan drawing on the master hub and on the tower page.
- Shared drawings are allowed only when project documentation explicitly groups towers together (for example West A-B and G1-G2).
- Never substitute a rendering, lifestyle image, generic site plan or another tower's plan for a missing drawing.
- Public pages do not expose research-source panels; provenance remains private in this file and the JSON asset manifest.
